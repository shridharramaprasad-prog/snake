# Snake — Arcade

A responsive Snake game built with React, TypeScript, and Vite.

## Run locally

1. Install Node.js (which includes npm).
2. In this project directory, run `npm install`.
3. Run `npm run dev` and open the local address printed in the terminal.

Create a production build with `npm run build`.

## Controls

- Arrow keys or W/A/S/D: steer
- P: pause or resume
- Space: start a run or play again
- Touch direction pad: steer on mobile

Each fruit is worth 10 points. The snake speeds up as your score increases, and your personal best is saved in this browser.
